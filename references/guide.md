# 阶段二：按问题模块写讲义

本文件与 `references/style.md` 在 `guide` 模式阶段二配合读取，沿已确认的框架逐模块成文。

## 全书骨架

全书仅含唯一 H1（`# <主题>`）、首尾两个固定节与按序编号的问题模块；历史演变融入对应问题模块：

| 节 | 内容与写法要求 |
| --- | --- |
| `## 全书导览` | 按顺位展开：① 用 1 个贴近日常的具体场景引出核心问题；② 水平树状 Mermaid 全书思维导图与阅读路线；③ 本书范围与边界、前置知识、阅读说明与考核要求（含明确不考项）。 |
| `## 一、……` 等问题模块 | 逐块展开核心主线（详见下文三段结构）。 |
| `## 全书速查与自测` | ① **核心概念与对比速查**：少数全书枢纽的适用前提与常见误区 + 竞争方案对照表；② **综合自测**：每模块 1–2 道紧扣原文的基础题（与正文各节自测题错开），先按序号集中列全题，再紧跟按对应序号排列的明文简明参考答案；③ **按需附注**（H3）：术语密集或含双语时加 `### 术语对照`（与 `_notes/plan.md` 的 `terms` 一致），存在 `[未解决]` 缺口或明确进阶书目时加 `### 延伸阅读与范围附注`，无则省略。 |

## 模块三段结构与单要点写法

### 模块三段结构
- **开场**：用一个具体的现实场景或困惑切入，自然承接前文或前置知识；仅在确实存在前序方案失灵且有具体事例时才写“A 不够所以有了 B”。
- **主体**：逐个展开本模块的枢纽、重点与常规要点，按篇幅自然起 H3 小标题（H2 用中文序号 `一、`、`二、`……，对应 H3 用数字序号 `1.1`、`1.2`……，首尾固定节不编号；标题文字部分均控制在 12 字以内）；「带过」要点用一两句附在相关要点后。
- **收尾**：用一句话收住本模块的核心结论，把引出下一困惑留给下一模块开场，两节交界处只追问一次。模块含「枢纽」或「重点」时，附 1–2 道基础级**本节自测**题（与 `practice.md` 基础档同难度：优先采用教材/课件基础原题，无原题时紧扣原文定义、机制与案例命题；先按序号集中列出问题，再在同块末尾紧跟对应序号的明文简明参考答案，直接展开供学习对照）。

### 三类内容展开方向与深浅配合
按知识点性质挑选最贴合的写作角度，融入自然行文：

| 内容类型 | 展开方向 |
| --- | --- |
| **概念 / 机制 / 方法** | 解决什么问题 → 是什么、怎么运作（配具体例子或步骤） → 适用前提与边界 |
| **观点 / 规律 / 现象** | 核心主张或现象是什么 → 靠什么事例、实验或证据立住 → 带来什么认知改变或启示 |
| **分歧 / 批判 / 选型** | 争论焦点是什么 → 各方主张、前提与主要局限（宜用对照表） → 本书立场与取舍依据 |

- **深浅配合**：「枢纽」与「重点」写全对应类型的 3 个角度；「常规」写透前 2 个角度（讲清意思 + 最有力的例子或理由）；「带过」一两句话附在相关段落后。
- **枢纽与难点**：枢纽在首次出场时一次讲透机制，后续模块用到时直接点名衔接前文并累积理解；标了 `（难点）` 的要点遵循“先主干再叠例外”，先用干净的标准场景建立直觉，再补前提限制、易混对比与反例。

## 论证、图表与来源纪律

默认语气、散文节奏、表格、引用块、标点与加粗规范统一见 `references/style.md`（若 `_notes/plan.md`「写作偏好」另有指定则以偏好为准）。本阶段额外遵守以下结构与取证规则：

- **先界定再使用**：任何支撑后文论证的概念，在首次使用前均由前置知识或更早位置界定清楚；出现公式时先讲直觉含义再写符号。
- **反向检验**：用生活场景、数量级或可观察现象讲完抽象机制后，改掉例子里的关键条件检查结论是否跟着变化——会变才算承载了机制，否则更换例子。
- **最短路径密度**：每要点保留一个最能说明机制的最短路径例子，剔除同质重复例证（细节留给读者回原书查阅）；概括总结与支撑材料二选一时留材料。
- **Mermaid 结构图规范**：
  - 坚持一图一任务，节点标签用 4–12 字精简短名（含括号或特殊符号时加双引号），无跨跳连线交叉；交叉引用直接写准确板块名、已有序号或自然位置词（如“1.1 节”）。
  - **全书思维导图**：用 `flowchart LR` 三层纯树展开（「全书核心 → 各模块 → 枢纽/重点/常规」）；节点统一圆角矩形、浅色底并写明深色文字；用单一浅灰灰度梯度区分层级，仅对「枢纽」用克制的浅蓝底色、重点用白底实框、常规用浅灰虚框，主次仅靠配色与线框区分；有目标标题的节点加 `click 节点ID "#标题锚点"`。
- **来源核实与断点查证**：事实依据每次回到原始素材或已记录的权威来源，不从前文反推；素材内部说法矛盾时并列说明差异与采纳理由；正文不挂引注，来源位置记入 `_notes/plan.md`。仅当缺失环节确实阻断后续主线推进、且原素材无法解决时，才定向联网查证权威原文（参考书、官方文档、原始论文），接回主线即停并将来源记入 `_notes/plan.md`；影响模块结构时按 `[结构调整]` 报用户，无条件补足则记 `[未解决]` 并在文末范围附注交代。

## 单板块完成标准

同时满足以下条件后，方可将本板块置为 `done`：
- 标题与 `sections[].title` 逐字一致，前置依赖、枢纽衔接与竞争方案取舍均已落实；
- 各要点深度匹配四档分级，抽象机制通过反向检验，事实全部回溯原始素材或已记录权威来源；
- 图表符合上述规范且紧跟首引段落，文风与版式符合 `references/style.md` 及「写作偏好」，术语符合 `terms`。
