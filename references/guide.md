# 阶段二：按问题模块写讲义

本文件与 `references/style.md` 在 `guide` 模式阶段二配合读取，沿已确认的框架逐模块成文。

## 全书骨架与固定模板

全书仅含唯一 H1（`# <主题>`）、首尾两个固定节与按序编号的问题模块；历史演变融入对应问题模块：

| 节 | 固定顺位与内容要求 |
| --- | --- |
| `## 全书导览` | 固定 4 块顺序：① 开篇场景与核心问题（1–2 段贴近日常的纯散文，不加行首标签）；② 导图引导句 + 固定图例文案 + `flowchart LR` 全书思维导图（色板与锚点规则见 `references/style.md`）；③ `**阅读路线**：...`；④ `**本书范围与阅读说明**：...`（含学科边界、前置知识、考核要求与明确不考项）。 |
| `## 一、……` 等问题模块 | 逐块展开核心主线（详见下文三段结构与固定收尾块）。 |
| `## 全书速查与自测` | 按下方固定 H3、表头与自测格式输出（综合自测每模块 1–2 道紧扣原文的基础题，与正文各节自测题错开）。 |

## 模块三段结构与单要点写法

### 模块三段结构
- **开场**：用一个具体的现实场景或困惑切入，自然承接前文或前置知识；仅在确实存在前序方案失灵且有具体事例时才写“A 不够所以有了 B”。
- **主体**：逐个展开本模块的枢纽、重点与常规要点，按篇幅自然起 H3 小标题（H2 用中文序号 `一、`、`二、`……，对应 H3 用数字序号 `1.1`、`1.2`……，首尾固定节不编号；标题文字部分均控制在 12 字以内）；「带过」要点用一两句附在相关要点后。
- **收尾**：用一句话收住本模块的核心结论，把引出下一困惑留给下一模块开场，两节交界处只追问一次。模块含「枢纽」或「重点」时，附 1–2 道基础级**本节自测**题（与 `practice.md` 基础档同难度：优先采用教材/课件基础原题，无原题时紧扣原文定义、机制与案例命题）。固定使用以下收尾块（纯常规模块省略引用块）：

```md
---

**本节小结**：<一句话收住本模块的核心结论>

> **本节自测**（先自己想一遍，再对照下方答案）：
> 1. <问题 1>
> 2. <问题 2>
>
> **参考答案**：
> 1. <简明答案 1>
> 2. <简明答案 2>
```

### 三类内容展开方向与深浅配合
按知识点性质挑选最贴合的写作角度，融入自然行文：

| 内容类型 | 展开方向 |
| --- | --- |
| **概念 / 机制 / 方法** | 解决什么问题 → 是什么、怎么运作（配具体例子或步骤） → 适用前提与边界 |
| **观点 / 规律 / 现象** | 核心主张或现象是什么 → 靠什么事例、实验或证据立住 → 带来什么认知改变或启示 |
| **分歧 / 批判 / 选型** | 争论焦点是什么 → 各方主张、前提与主要局限（宜用对照表） → 本书立场与取舍依据 |

- **深浅配合**：「枢纽」与「重点」写全对应类型的 3 个角度；「常规」写透前 2 个角度（讲清意思 + 最有力的例子或理由）；「带过」一两句话附在相关段落后。
- **枢纽与难点**：枢纽在首次出场时一次讲透机制，后续模块用到时直接点名衔接前文并累积理解；标了 `（难点）` 的要点遵循“先主干再叠例外”，先用干净的标准场景建立直觉，再补前提限制、易混对比与反例。

## 论证、图表与来源纪律

默认语气、散文节奏、版面标点、跨节引用与 Mermaid 配色统一见 `references/style.md`（若 `notes/plan.md`「写作偏好」另有指定则以偏好为准）。本阶段额外遵守以下规则：

- **先界定再使用**：任何支撑后文论证的概念，在首次使用前均由前置知识或更早位置界定清楚；出现公式时先讲直觉含义再写符号。
- **反向检验**：用生活场景、数量级或可观察现象讲完抽象机制后，改掉例子里的关键条件检查结论是否跟着变化——会变才算承载了机制，否则更换例子。
- **最短路径密度**：每要点保留一个最能说明机制的最短路径例子，剔除同质重复例证（细节留给读者回原书查阅）；概括总结与支撑材料二选一时留材料。
- **图表位置与配色**：全书导图与正文局部图严格复用 `references/style.md` 的固定色板、方向规则与锚点写法，不另行配色；图表紧跟首次引用它的正文段落。
- **来源核实与断点查证**：事实依据每次回到原始素材或已记录的权威来源，不从前文反推，出处定位与译名能核实到哪一级就标到哪一级；素材内部说法矛盾时并列说明差异与采纳理由；正文不挂引注，来源位置记入 `notes/plan.md`。仅当缺失环节确实阻断后续主线推进、且原素材无法解决时，才定向联网查证权威原文（参考书、官方文档、原始论文），接回主线即停并将来源记入 `notes/plan.md`；影响模块结构时按 `[结构调整]` 报用户，无条件补足则记 `[未解决]` 并在文末范围附注交代。

## 单板块完成标准

同时满足以下条件后，方可将本板块置为 `done`：
- 标题与 `sections[].title` 逐字一致，前置依赖、枢纽衔接与竞争方案取舍均已落实；
- 各要点深度匹配四档分级，抽象机制通过反向检验，事实全部回溯原始素材或已记录权威来源；
- 固定区块模板、图表色板、版式微规范与 `references/style.md` 及「写作偏好」一致，术语符合 `terms`。
