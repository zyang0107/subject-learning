# 测验与复习

核心分工：**全部题目、参考答案、得分要点与干扰项依据集中在 `<主题目录名>-习题册.md`**；`_notes/quiz.md` 只记做题指针、分模块对错统计与用户错因；`<主题目录名>-错题本.md` 专供读者复盘错题与主线纠偏；正文 `<主题目录名>.md` 保持不变。

## 第一步：生成习题册

主题目录下尚未生成 `<主题目录名>-习题册.md` 时，先在顶层生成（与主文档同目录）：

- **结构与版式**：唯一 H1 为 `# <主题> · 习题册`，文首固定 2 段（1 句关联主讲义链接 + `- **题量与分布**：共 **N 题**（基础 X 题 · X%，进阶 Y 题 · Y%）；选择题 A 题（A%）、判断题 B 题（B%）、问答题 C 题（C%）。`）；其后按主讲义问题模块分节（`## 一、……`）。每节内按固定顺序归类排列——`**选择题**` → `**判断题**` → `**问答题**`，同题型内先基础后进阶、全节连续编号（`1.`–`N.`）；节末用 `### 参考答案与得分点` 按对应题号集中给出明文答案。
- **固定标签语法**：每题紧跟题号用行内代码写 3 段式标签 `` `[来源 · 题型 · 难度]` ``——来源固定取 `原题（<原位置>）` / `自拟` / `专项`；题型固定取 `选择` / `判断` / `问答`；难度固定取 `基础` / `进阶`。
- **全覆盖与配额**：优先收录素材原题，再对照 `_notes/plan.md` 与主讲义补题，确保**同一模块下的每一个小节与要点均有题覆盖**；允许对同一核心机制换例证、换问法或改条件出多道相似变式题。
  - **推荐配额**：**枢纽**每点 4–5 题，**重点** 3–4 题，**常规** 2–3 题，有代表性案例或易混点的**带过**要点 1–2 题。
- **难度与题型比例**（课程有真题分布时优先贴合真题）：
  - **难度**：**基础 60%–70%**（紧扣教材/课件原文机制与概念辨析，与正文自测同难度层）｜**进阶 30%–40%**（新场景迁移、边界判断与竞争方案对比）。
  - **题型**：**选择题 55%–65%**（占大头）｜**判断题 20%–30%**（为辅）｜**问答题 0%–20%**（作补充，上限不超过 25%；无需长篇作答的模块可不出）。

### 三类题型的出题标准

全册题目严格限定在以下三类内（课程考试另有必考题型时，以素材原题为准）：

1. **选择题（4 选 1 单选）**
   - **选项四条准入条件**：① **同类同级**（四项同属一个概念类别与抽象层级）；② **句式与详略一致**（条件完整度相当）；③ **字数配平**（正确项字数与其他三项均值之比保持在 **0.8–1.2 倍**，补齐字数靠增加具体可核验的前提或推论，保持措辞克制）；④ **严肃度与立论姿态一致**（把每一个干扰项都当成真实存在的严肃观点来认真辩护，书面语域与严谨程度与正确项齐平）。
   - **干扰项 6 种单点偏移构造法**（与正确项保留大部分相近成分，只改 1 个关键点）：① 角色或属性互换（两半真话对调归属或因果方向）；② 同类相邻替换（换用同分类兄弟概念）；③ 边界过宽或过窄（抹去前提或拿特例当通则）；④ 前半真、后半偏（正确前提后接错误推论）；⑤ 真话答偏维度（原文正确但回答另一层问题）；⑥ 表面词句诱饵（原词塞入错项、正确项改同义转述）。
   - **出完三项自查**：① **遮选项自答**（只看题干即可明确要找哪类结论）；② **遮题干看四选项**（单看 A/B/C/D 的严谨度、长度与姿态难分真假，四项互不包容、独立排他）；③ **位置均衡**（正确选项在 A/B/C/D 间分布大致均匀）。
2. **判断题（判断并说明理由）**
   - 先判正误再用 1–2 句话讲清机制依据或前提漏洞，**理由为主要得分点**；
   - 每题聚焦单一明确命题，语气温和平实；错误命题把误区落在真实机制或边界上，同时专门编入“直觉看着像错、按原文其实成立”的正确命题，真假大致均衡。
3. **问答题（基础考机制与分界，进阶考新场景分析）**
   - **基础问答**：提问明确限定角度与要素数量，聚焦“为什么 / 怎么变 / 分界在哪”，参考答案拆成 2–3 条独立得分短句。
   - **进阶问答**：选用原文未出现过的新生活/工作场景，场景中的具体条件必须直接决定得出哪条结论（抽走情景即无法作答），内置真实张力并去掉无关背景；按三层设问与给答案——① 核心概念或机制；② 场景中的关键依据；③ 改掉某关键条件后的结论变化。

### 习题册固定排版模板

```md
**选择题**

1. `[自拟 · 选择 · 基础]` <题干>
   - A. <选项 A>
   - B. <选项 B>
   - C. <选项 C>
   - D. <选项 D>

**判断题**

6. `[自拟 · 判断 · 基础]` <单一明确命题>

**问答题**

8. `[自拟 · 问答 · 进阶]` <新场景描述>
   请回答：
   ① <核心概念或机制>
   ② <场景中的关键依据>
   ③ <改掉某关键条件后的结论变化>

### 参考答案与得分点

1. **答案：B**
   - **依据**：<简明机制依据>
   - **干扰项排除**：A <错因>；C <错因>；D <错因>。

6. **答案：正确 / 错误**
   - **得分要点**：
     1. <要点 1>
     2. <要点 2>

8. **参考答案**
   - **核心识别**：<核心概念或机制>（基础问答改用 `- **得分要点**：` 下接 `1.` `2.`）
   - **结合场景分析**：<场景关键依据>
   - **条件变化推演**：<改条件后的结论变化>
```

**习题册完成标准**：`_notes/plan.md` 每个模块下的全部小节与要点均已覆盖；总题量与基础/进阶、三类题型比例落在目标区间；全部选择题通过三项自查；版式、标签与节末答案严格符合上述模板且题号一一对齐。

## 第二步：对话测验（以 `_notes/quiz.md` 为指针）

开测前先读 `_notes/quiz.md`（无则新建），确认**范围**（指定模块 / 全书 / 错题本）与**模式**：

| 模式 | 选定题目与推进方式 |
| --- | --- |
| **顺序刷** | 沿 `<主题目录名>-习题册.md` 顺着模块逐题出（每节先选择 → 判断 → 问答，先基础后进阶），跳过 `_notes/quiz.md` 中 `已过` 的题；已有待复习错题时，每出 2–3 道新题安排 1 道最久未复习的错题（不连着两轮出旧题） |
| **打乱刷** | 在选定范围内打乱模块与题序从习题册抽题（或就关键机制微调条件出成变式并先补入习题册），避开已答对题号；同要点先出 1 道基础题、答对再出 1 道进阶题，连对两道换下一点；答错则记录错因，隔 2–3 轮再出同类题复习 |
| **只看错题** | 专练 `<主题目录名>-错题本.md` 中状态为 `待复习` 或 `复习过1次` 的条目（记忆类考原要点，理解类换同类题），答对逐步推成 `已掌握` |

- **一题一判与固定出题格式**：每次只发 1 题，隐去答案与提示，同步更新 `_notes/quiz.md` 的 `current` 指针；学习者随时可说“跳过”“换模块”或“结束”。发题固定按以下格式输出，不加多余寒暄：

```md
**[习题册 · 模块二第 5 题｜选择 · 基础]**（第 3 轮 · 打乱刷）

<题干与选项>
```

- **对照习题册判分与固定反馈三段**：作答后读取 `<主题目录名>-习题册.md` 对应答案与得分要点，同步更新 `_notes/quiz.md` 的分模块统计与流水记录（记下用户原话反映的做错理由），并固定按三段反馈：
  1. `**判定：完全正确**` / `**判定：部分正确**` / `**判定：答错**`（选/判题同行附标准答案，如 `（答案：B）` 或 `（答案：错误）`）；
  2. `**解析**：`答对一句话确认要点；答错或部分正确区分两类——**记忆性错误**直接纠偏并给简明区分点，**理解性错误**先读 `_notes/plan.md`「学习定位与要求」与对应模块，沿学科核心问题与解决主线点出“回答默认了什么前提、会在哪一步讲不通”并指回正文 `X.Y 节`；
  3. 仅在写入或更新 `<主题目录名>-错题本.md`（首次出错时在顶层创建，按 `待复习` → `复习过1次` → `已掌握` 追踪，再错退回 `待复习`）时用一句话提示，随后直接出下一题或等待指令。

## 第三步：测后回顾与专项突破

一轮结束（或学习者要求回顾）时，读 `_notes/quiz.md` 固定按以下一屏结构输出回顾：
1. 分模块统计表（直接复用 `_notes/quiz.md` 的表头与数据）；
2. `**表现稳定**：...`
3. `**薄弱环节与共性错因**：...`
4. `**下一步练习建议**：...`

随后按四条原则调整出题：
1. **答得好的部分**：少出题或跳过基础题；
2. **错得多的部分**：发起专项突破，出同类新题或换题型角度拆解；
3. **质量标准不变**：专项新题严格遵守前文三类题型的全部规范；
4. **难度适当放低**：提高基础题比例，用更直观的小场景建立把握，稳住后再恢复常规比例。专项新题及答案直接插入 `<主题目录名>-习题册.md` 对应模块的相应题型块与节末答案（标注 `` `[专项 · 题型 · 基础/进阶]` `` 并顺延编号）。
